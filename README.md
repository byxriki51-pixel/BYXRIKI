# Bot WhatsApp Riki

Bot WhatsApp sederhana pake Baileys

## Fitur
- .menu - Liat menu
- .ping - Cek bot online
- .cek - Fitur tambahan

## Cara Install
1. Clone repo ini
   git clone https://github.com/username-kamu/bot-wa-riki.git
2. Masuk folder
   cd bot-wa-riki
3. Install library
   npm install
4. Jalanin bot
   node index.js
5. Scan QR pake WhatsApp

## Dibuat dengan
- Node.js
- @whiskeysockets/baileys
